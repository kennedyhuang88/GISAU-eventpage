# GISAU-eventpage (practice project)

Live page: https://kennedyhuang88.github.io/GISAU-eventpage/

A mobile-friendly concept page for an existing "Indomie Eating Competition" event from GISAU, made as a practice project while I learn HTML and CSS.

This is not an official GISAU page. The event details are made up, and the design is only inspired by GISAU's website.

## What it includes
- A hero section with an illustrated bowl drawn in SVG
- A simple menu that opens without JavaScript
- An event details list and a register button
- A layout that adapts to phone and desktop screens

## What I learned
- How an HTML page is structured
- Styling with CSS (colours, fonts, spacing, layout)
- Making a page responsive with a media query

## Built with
HTML and CSS only. I started from a template generated with Claude (an AI assistant), then edited the text, colours, and details myself.
